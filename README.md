# Pesa Track

Suivi de dépenses multi-devises en Python.

## Fonctionnalités
- Ajouter une dépense (montant, devise, catégorie)
- Voir toutes les dépenses
- Sauvegarde automatique dans un fichier JSON

## Lancer le projet
```
py main.py
```
